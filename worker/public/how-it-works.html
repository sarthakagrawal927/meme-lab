PERSONAL TOOL

THE LIVE 300

Retrieve first. Rank second.

Each reference has a name, meaning, relational pattern, example, tags, provenance, and media status. Vector search narrows 300 records to the 30 most relevant before reranking.

  1. 01Validate

    Trim and bound the comment. Treat it as untrusted text.

  2. 02Retrieve 30

    Use BGE embeddings and Vectorize to find the closest semantic matches.

  3. 03Rank and score

    Llama judges tone and social fit, then returns known IDs with 0–100 scores.

  4. 04Show up to three

    Load the plausible previews, best first, and store optional feedback for 30 days.

THE RETRIEVAL SYSTEM

The same path scales beyond 300.

Putting hundreds or thousands of records into every prompt would be slower and harder to evaluate. Semantic retrieval keeps the prompt bounded while the reranker preserves judgment.

THE EVAL DATASET

50 held-out situations before the next jump.

The control set contains 20 humour and 10 no-meme cases; a second set adds 20 expansion-only cases to prove the larger catalogue adds useful coverage.

  • Top 1Did the first choice land?
  • Top 3Was any shown option sendable?
  • AbstentionDid it stay serious when humour did not belong?
  • CalibrationDid low confidence actually mean weaker results?

Latest draft: a meaning-specific metadata pilot reached 95% expansion-only retrieval and 80% top-three relevance. The personal tool is live; these labels guide continued tuning.

THE EXPANSION RULE

Bigger is useful only if the results stay good.

The personal catalogue stays available while evaluation tracks top-three relevance, correct no-meme decisions, valid IDs, and latency. Weak metadata gets fixed from observed failures.
