CONTROL STAGE

THE LIVE 30

Small enough to compare everything.

Each reference has a name, meaning, relational pattern, good example, near-miss example, tags, provenance, and media status. The whole set fits in one bounded model request.

  1. 01Validate

    Trim and bound the comment. Treat it as untrusted text.

  2. 02Compare all 30

    Send every enriched reference to Llama 3.3 through Workers AI.

  3. 03Rank and check

    Accept only known, distinct IDs with structured reasons and confidence.

  4. 04Show up to three

    Load every plausible preview, best first, and store optional feedback for 30 days.

THE EXPANDED SYSTEM

At 3,000, retrieve first. Rank second.

Putting thousands of records into every prompt would be slower, costlier, and harder to evaluate. The expanded system uses semantic retrieval to preserve speed while the same reranker preserves taste.

THE EVAL DATASET

50 held-out situations before the next jump.

The control set contains 20 humour and 10 no-meme cases; a second set adds 20 expansion-only cases to prove the larger catalogue adds useful coverage.

  • Top 1Did the first choice land?
  • Top 3Was any shown option sendable?
  • AbstentionDid it stay serious when humour did not belong?
  • CalibrationDid low confidence actually mean weaker results?

Latest draft: the 300 path preserved the original cases, but failed the expansion-only coverage set. The new metadata needs repair before promotion.

THE PROMOTION RULE

Bigger is useful only if the results stay good.

Every stage must preserve top-three relevance, correct no-meme decisions, valid IDs, and acceptable latency. If a larger catalogue fails, the live collection stays on the last passing stage.
