THE JOURNEY

Each scale jump solved a different problem.

The catalogue did not jump straight to 3,000. Each stage stayed live, exposed a limitation, and supplied the evidence for the next stage.

01 · CONTROL30 useful reactions

The original release held 60 records: 30 reaction candidates and 30 caption templates. The picker deliberately used the 30 reactions as a small all-candidate control so every model choice could be inspected.

02 · COVERAGE300 common references

Two hundred and forty reviewed external records expanded the vocabulary. Vector retrieval replaced direct comparison, the collection became searchable, and the first public feedback loop went live.

03 · GENERALIZATION1,000 broader references

Seven hundred long-tail records forced dual-view retrieval, a fresh 60-case shadow set, a serious-content gate, and the first classifier bake-off. This is where Jev beat embedding-only ranking.

04 · SCALE3,000 live references

A 2,227-record source pool produced 2,000 additions after provenance, exact-copy, perceptual, alias, and CLIP checks. The live index now stores a meaning vector and a usage-example vector for every reference.

05 · QUALITYFive options, real viewpoints

Complete sentence examples revealed that one situation can support the narrator’s reaction, the other person’s side, and the event itself. The UI now returns one primary choice and four visible backups across those angles.

06 · CALIBRATIONLabels instead of fake probability

Jev’s old competitive score looked like a probability but was not one. A blind hard-case evaluation selected independent ordinal ratings, so the product now says weak, plausible, strong, or exact.

WHAT REAL USE CHANGED

The product became simpler while the ranking became deeper.

The interface is intentionally one action: paste a complete comment and get a meme. The technical complexity stays behind that action.

Input

Full sentences, not keywords

Examples describe the whole situation so actor roles, quoted speech, negation, relationship, and emotional tone survive retrieval.

Output

One best choice plus four backups

The best result remains visually dominant. Four lower-ranked options stay visible because humour is subjective and several reactions can be valid.

Viewpoint

My reaction, their side, the situation

Multi-person comments deliberately search all three angles instead of assuming every meme must speak only for the person who typed the comment.

Confidence

Weak is shown honestly

A weak but usable option is labelled weak. The system abstains only when humour would be insensitive or every candidate would misrepresent the situation.

Interaction

No generated explanation step

The user asked for a meme, not a paragraph. Removing live reasoning reduced latency and stopped plausible-sounding prose from disguising a mediocre match.

Feedback

A small yes or no loop

One-tap feedback is retained for 30 days for evaluation. It does not silently retrain or overwrite the catalogue.

THE LIVE 3,000

Retrieve. Compare. Return.

Every reference has a name, meaning, relational pattern, full-sentence example, near-miss, tags, provenance, media state, meme-strength score, and image-quality score. Runtime work stays bounded even as the catalogue grows.

  1. 01Validate and guard

    Trim and bound the comment, treat it as untrusted text, and catch clear factual or serious help requests before joking.

  2. 02Retrieve 30

    Embed the full comment, search meaning and usage-example vectors separately, then fuse both ranked lists.

  3. 03Compare by fit

    Jev independently rates all 30 candidates. Multi-person comments also preserve explicit narrator, other-person, and situation lenses.

  4. 04Return five

    Show one primary result and four backups labelled weak, plausible, strong, or exact. Persist only the bounded evaluation record.

Twenty shortlist slots search the full catalogue; ten reserve candidates from the original 1,000 so noisy expansion records cannot erase the stronger base.

Jev fast

Perspective mode

Three lens passes select distinct viewpoint candidates. A final batch rates the selected five on the same ordinal scale before the UI orders them.

Fallback

The larger model is exceptional

The structured 70B selector runs only if classifier ranking fails. It is resilience, not an explanation step on every request.

HOW 3,000 WAS BUILT

Acquisition was easy. Uniqueness was the work.

The stage-3,000 pool combined canonical meme sources with public-domain art. Automated checks block exact copies and surface fuzzy lookalikes without pretending semantic similarity always means duplication.

  1. 01
    Identify the source

    Keep provider, canonical source URL, media URL, licence URL when available, and an explicit preview-rights state.

  2. 02
    Block hard duplicates

    Compare canonical URLs, exact bytes, normalized names, and conservative aliases before a record can enter selection.

  3. 03
    Detect visual near-copies

    Perceptual hashes flag resized or transformed versions of the same image. Ten embedding-near candidates were separately surfaced for review.

  4. 04
    Measure embedding uniqueness

    A local quantized CLIP model checks visual neighbourhoods. Similar meaning can remain if the actual reaction and image are usefully distinct.

  5. 05
    Score the collection—not relevance

    Selection used 62% meme strength, 18% asset quality, and 20% embedding uniqueness. These values never claim that a meme fits a new comment.

  6. 06
    Write specific metadata locally

    Local Qwen generated complete meaning, social-dynamic, example, near-miss, and tag sentences. They remain assistant-authored pending owner feedback.

Not run

Gemini structured output was not called because the repository has no bounded experiment credential. No result is claimed for it.

The lesson

More reasoning was not automatically better. Rich, specific candidate data plus an independently judged ordinal task was the strongest quality/cost combination.

THE EVALUATION LADDER

One hundred broad cases plus twelve hard ranking cases.

The 100-case suite measures retrieval, ranking, and serious-content behavior across 75 humour and 25 no-meme situations. A separate 12-case hard set isolates the fit-score problem across 101 unique comment-and-candidate pairs.

  • RetrievalDid an acceptable reference enter the top 30?
  • Top one / top threeDid ranking put a sendable choice near the front?
  • AbstentionDid serious requests avoid an inappropriate joke?
  • CalibrationDo weak, plausible, strong, and exact mean something consistent?

Pre-ordinal 100-case snapshot: retrieval reached 72% at 30, 67% top-one relevance, 71% top-three relevance, and 96% correct serious-content abstention. All labels remain pending owner review.

THE LATEST QUALITY DECISION

Independent labels beat competitive probability.

The original Jev number was a probability inside a 30-way competition, not “the chance this meme is good.” We corrected a contradictory refrigerator fixture, rebuilt every arm, formed a 101-pair union, and had a fresh model rate the pairs blind to arm identity and scorer output.

The largest remaining slowdown

Multi-person mode performs three perspective-specific classifier passes and one final ordinal rescore. Remote embedding, Vectorize, classifier networking, and D1 persistence add smaller fixed costs.

The safe optimization order

First lock owner-reviewed quality. Then test one structured batched perspective call, compact metadata, and production p50/p95 tracing against the same cases. Do not trade the recovered viewpoints away for a synthetic speed win.

STORAGE, MEDIA, AND COST

The catalogue is stored. Most image files are not.

The build pipeline is mostly local, but the live runtime is not yet completely local or free: it currently uses Cloudflare Workers AI, Vectorize, D1, and classifier.dev.

CATALOGUE

Versioned JSON and generated modules

Names, meanings, examples, near-misses, provenance, quality signals, and source URLs live with the project and generate the public collection.

SEMANTIC INDEX

6,000 vectors in Vectorize

Meaning and usage vectors are stored remotely so every request searches a bounded index instead of loading all 3,000 records.

IMAGES

Provider-hosted previews

Imgflip, Memegen, and National Gallery images load from their source URLs. Meme Lab does not silently rebundle media or imply redistribution rights.

RIGHTS

CC0 and source previews stay distinct

National Gallery CC0 originals link to their licence. Other source previews remain labelled “media rights not established.”

FEEDBACK

Bounded D1 records

The comment, returned candidate IDs, decision, labels, and yes/no feedback support evaluation and receive a 30-day expiry.

LOCAL WORK

CLIP and Qwen built the collection

Uniqueness signals and long-form metadata were generated locally. The fastest local routing models tested so far were not accurate enough for the live decision.

WHAT WE STOPPED DOING

The discarded ideas matter too.

This history prevents the project from repeating attractive experiments that already failed the quality, speed, or honesty bar.

  • Embeddings alone: good for neighbourhoods, weak at deciding whether a reaction is socially sendable.
  • Generated reasoning on every result: slower and unnecessary; fluent prose could make a poor selection sound convincing.
  • Raw Jev probability in the UI: useful for competition ordering, misleading as user-facing confidence.
  • One perspective for every sentence: lost valid reactions from the other participant or the situation itself.
  • Static meme strength as relevance: a famous or high-quality image can still be the wrong response.
  • Jev smart and serial ensembles: 5–14 second paths were too slow without a matching quality gain.
  • Current small local routers: cheap and private, but too eager to abstain from genuine humour.
  • Claiming model labels as truth: every metric remains visibly marked pending owner review.

THE RULE THAT SURVIVED EVERY STAGE

Bigger is useful only if the results stay honest.

Three thousand is live, not “finished.” The collection is machine-curated, evaluation labels are not yet human ground truth, source previews do not imply media rights, and a weak match stays visibly weak. The next improvement comes from owner feedback and replayable evidence—not a more impressive model name.
