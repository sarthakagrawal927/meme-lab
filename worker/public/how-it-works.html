PERSONAL TOOL

THE LIVE 3,000

Retrieve. Classify. Explain.

Each reference has a name, meaning, relational pattern, example, provenance, media status, meme-strength score, and image-quality score. Two semantic views narrow 3,000 records to 30. If more than one person is involved, the classifier deliberately chooses distinct memes for my reaction, their side, and the situation.

  1. 01Validate

    Trim and bound the comment. Treat it as untrusted text.

  2. 02Retrieve 30

    Search meaning and usage-example vectors separately, then fuse both ranked lists.

  3. 03Guard and rank

    Jev checks sensitive help-seeking text, then ranks once or through three explicit perspective lenses. Weak viewpoint alternatives are omitted instead of forced.

  4. 04Return immediately

    Jev's scores become fit scores. Weak alternatives are omitted; the larger fallback model stays off the normal path.

THE RETRIEVAL SYSTEM

The path scales to 30,000.

At 3,000, retrieval keeps the prompt bounded. Relevance chooses the eligible three first; static meme strength and image quality only reorder genuinely close calls. At 30,000, a router will choose meme, movie dialogue, or no reaction before searching the matching corpus.

THE EVAL DATASET

100 labelled situations guide the next jump.

The original and expansion sets cover 50 situations. The 1,000-meme work added a 60-case tuned regression set and a fresh 60-case shadow set. The 3,000-meme gate keeps that independent shadow set and adds 40 long-tail cases, for 100 cases total. Labels remain pending owner review.

Current 100-case set: retrieval reached 72% at 30, 67% top-one relevance, 71% top-three relevance, and 96% correct serious-content abstention. The fresh long-tail slice reached 93% retrieval and top-three. Labels remain pending owner review.

THE EXPANSION RULE

Bigger is useful only if the results stay good.

Every expansion record must clear provider/source identity, canonical URL, exact-byte hash, perceptual-image, normalized-name, alias, and meaning checks. Exact duplicates are blocked automatically; fuzzy visual or semantic matches go to review. The personal catalogue stays available while evaluation tracks top-three relevance, correct no-meme decisions, valid IDs, and latency.
