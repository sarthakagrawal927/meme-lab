PERSONAL TOOL

THE LIVE 1,000

Retrieve. Classify. Explain.

Each reference has a name, meaning, relational pattern, example, tags, provenance, and media status. Two semantic views narrow 1,000 records to 30 before a dedicated classifier ranks the best three.

  1. 01Validate

    Trim and bound the comment. Treat it as untrusted text.

  2. 02Retrieve 30

    Search meaning and usage-example vectors separately, then fuse both ranked lists.

  3. 03Guard and rank

    Jev checks sensitive help-seeking text and ranks the three closest social reactions.

  4. 04Explain three

    Llama writes specific explanations and fit scores without changing the ranked IDs.

THE EVAL DATASET

170 labelled situations guide the next jump.

The original and expansion sets cover 50 situations. The 1,000-meme work adds a 60-case tuned regression set plus a fresh 60-case shadow set; both contain 45 humour and 15 no-meme prompts. Labels were independently cross-audited and still need owner review.

  • Top 1Did the first choice land?
  • Top 3Was any shown option sendable?
  • AbstentionDid it stay serious when humour did not belong?
  • CalibrationDid low confidence actually mean weaker results?

Fresh shadow set: dual-view retrieval reached 64% retrieval, 56% top-one relevance, 64% top-three relevance, and 100% correct serious-content abstention. The separate tuned regression set reached 96% top-three. Labels remain pending owner review.
